# Monochrome ERP symbols

Existing ERPNext SVG geometry with palette-only ink/white variants. Original SVGs remain in the parent folder. No CSS image filter is used.

Workflow uses Font Awesome Free 6.7.2 shuffle (the successor to fa-random, which is the icon named in Frappe Workflow metadata).
