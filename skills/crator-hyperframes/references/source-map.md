## Reference analysis

The original local study is `~/dev/crator-launch-video/references/close-study-20260909/DIRECTION.md`, with contact sheets and clips nearby. Its 0.5-second sampling exposed the difference between decorative movement and scenes driven by actions. The skill's techniques reference generalizes that study; historical prices/colors/copy in the old study are superseded by later feedback.

- **Softriver** — https://x.com/chddaniel/status/2095775049475313943 : recognition through giant type; input as an object; cluster-to-sentence transition; overscanned fields; curve-following camera. Useful for typography, scale, density and connected transitions.
- **GitHub Sync** — https://x.com/motion_so/status/2095958591668621758 : composer → import menu → generated app → toolbar → changed-file list. Camera targets follow real product actions, rather than repeated progress beats.
- **Muse** — https://x.com/Muse/status/2097399178376671666 : objects embedded in sentences, one message or record extracted into the foreground, persistent context across very different scales and surfaces.
- **HeyGen source** — https://github.com/heygen-com/hyperframes-launch-video : actual source to inspect for camera, object and background implementations. The user specifically selected this repository over another proposed source. Original clone was under `~/dev/crator-launch-video/references/heygen-hyperframes-launch-video`.
- **Claude for people search** — https://x.com/jasonzhou1993/status/2094740336895840605 : recognizable comparison hook. Inspect the original for motion; do not reduce it to “put Meet in small type.”

These are references, not blanket authorization to republish their footage or audio. Use known local copies for analysis when present. Attribute third-party marks and assets appropriately in project records.
